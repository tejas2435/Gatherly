# ✨ Gatherly

### A Modern Full-Stack Social Media Platform  
**Where People Come Together**

Built with **React · Node.js · Express · PostgreSQL · Supabase · Socket.IO**

🔗 **Live Demo:** https://gatherly-lemon.vercel.app/

---

# ⭐ Overview

Gatherly is a full-stack social media platform featuring secure user authentication, image-based posting, followers, real-time chat, notifications, and profile management. Images are securely stored using Supabase Storage, while real-time messaging and notifications are powered by Socket.IO. The frontend is deployed on Vercel and the backend on Render.

---

# 🚀 Features

## 👤 User Accounts
- Signup & Login with JWT Authentication
- Secure Password Hashing (bcrypt)
- Edit Profile Information
- Upload Profile & Cover Photos
- Public User Profiles

## 📝 Posts & Feed
- Create Posts with Text & Images
- Image Upload Support
- Personalized Feed
- View User Profiles & Posts

## 👥 Followers & Explore
- Follow / Unfollow Users
- Suggested Users
- Followers & Following Lists
- Follow Status Management

## 🔔 Notifications
- Instant Follow Notifications
- Unread Notification Counter
- Mark All as Read
- Delete Individual or All Notifications
- Real-Time Notification Updates

## 💬 Real-Time Chat
- One-to-One Messaging
- Socket.IO Powered Communication
- Instant Message Delivery
- Auto-Updating Chat List

## 🔍 Search
- Search Users by Name or Username
- Profile Images in Search Results

## 🎨 UI / UX
- Modern & Responsive Design
- Light / Dark Theme Support
